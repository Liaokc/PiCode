# 弃用上一版 MVP 基线，从零重建

仓库 git 历史中存在一版完整 MVP（host 层经 Pi SDK 直连、审批闸门、会话侧边栏等，见 `3ba10fd..2b5c3ed`）。项目所有者判定该版质量不佳，于 2026-08-27 决定将其整体弃案：工作区的删除不回滚，PiCode 以全新代码重建。

## Considered Options

- 在 HEAD 基线上恢复源码并重写 renderer 层 —— 被拒：所有者对既有实现质量不满，重写范围实际覆盖了架构感知层面，保留旧地基收益有限且带来心理包袱。
- 从零重建（选定）：旧代码仅存于 git 历史，可考古但不再引用。其中沉淀的事实结论（Pi SDK 可行性、会话 jsonl 可解析性）依然有效，属于经验而非资产。
