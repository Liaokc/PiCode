# 内置终端采用完整 PTY 并含 agent 桥接

项目所有者裁定内置终端进入 1.0 且选择最高规格：xterm.js + node-pty 的完整交互式终端（用户可自行敲命令，与 agent bash 各自独立 shell 会话），并包含**桥接（Bridge）**能力——agent 执行中的 bash 工具命令可投屏至该终端视图查看实时输出。为此明确接受更高的工时投入，里程碑从 M6 独立模块升级为重点分工项。

## Consequences

- 需要在 host 子进程与渲染层之间建立终端专用的高吞吐数据通道（pty 输出不能走普通 JSON 事件流逐条序列化再转发，需评估二进制/批量通道）。
- 桥接为单向观察（投屏输出），不把用户的终端输入回注给正在运行的 bash 工具；双向接管不在 1.0 承诺内。
