## R1（机械，根因已定位）：t91 closedIntact91 单快照

- `src/main/smoke.ts` closedIntact91（~9666）：`const s = await sample91()` 后**立即**判 `if (s.open) fail(...)`——本段其余断言（open/walk/count 探针）全有 5s waitForProbe，唯独「退出后关闭」是单次快照。mask-blank 腿（真鼠标 mouseDown→60ms→mouseUp 后立刻采样）在渲染负载下 React 提交晚于快照 → 误报 `the overlay never closed via the mask-blank click exit`（7b 实测：Space/❌/Escape 三腿全过、唯 mask-blank 死）。
- 修法：open 检查改为有界 settle-poll（waitForProbe 轮询「overlay 已关」≤5s，与本段兄弟断言一致）；「关闭且 composer 无扰 + 光标回位」断言语义不变——5s 内没关仍是真失败。四个退出腿（Space/❌/Escape/mask-blank）同享修复。

## R2（诊断+修复授权）：t90 live 徽章 10s 探针死

- 现象（dev跑3，`/tmp/t141-smoke-3.log`）：`ticket-90 stage: the live run never flipped to a Running badge from the artifact`——③腿 writeArtifact90('running') + 桥接 roundtrip **已解**（`statusRt1` waitFor 命中 subagent_status state=running），但 `[data-subagent-row="s90-call-live"] .subagents-badge-running` DOM 探针 10s 未翻。
- 诊断假说（按序查证）：①新 subagent_status 事件触发 subagents 区重渲染时**分页复位**——行退回「Show 20 more」之后，选择器找不到（查 Ended→Running 区移动与 show-more 状态交互）；②事件到达 harness 观测点但未前送到 renderer（桥接转发路径）；③renderer 收到但增强路径没跑（runId/artifact 匹配、store 键）。
- 取证手段：t44 规范「前移位取证」——临时把该 fail 改 log-and-continue + 每秒 DOM dump（行在不在 DOM、在哪个 section、show-more 状态），跑通取证后**复原断言原文**。修复落点据证据定（可能是 harness 探针/驱动顺序问题，也可能是产品增强真缺陷——据实报告）。
- t90 自 1.8 批以来被 t89 掩蔽从未到达，不排除与 t89 同类的确定性破；也可能是负载时序。证据说话。

## R3（诊断+修复授权）：t119 底钉漂移

- 现象（dev跑4，`/tmp/t141-smoke-4.log`）：`ticket-119 stage: the attachment strip moved the bottom-pinned reader off the bottom...DOM: {"st":1810,"ch":527,"sh":2381,...,"tailIn":false}`——死前**背景 24 连 thinking_delta 流式负载**。
