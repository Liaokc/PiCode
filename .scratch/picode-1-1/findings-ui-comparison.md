# PiCode ↔ ZCode 实机比对取证记录（2026-08-31）

需求收集会话执行。方法：双 app 实机截图 + 源码核对 + ZCode 会话库（`~/.zcode/cli/db/db.sqlite`，**只读**）检索。操作者授权口径：打开 ZCode 操作截图、只读查询其会话记录，用于功能比对取证；不写 ZCode 任何数据。

## 工具与环境

- `screencapture -l<windowID>`（CGWindowID 直截，免疫 Spaces）+ 自编译 `/tmp/mouse`（CGEvent 移动/点击/滚轮）+ AppleScript（激活/键入/窗口几何）。
- 窗口几何：ZCode 主窗 ID 48，PiCode 主窗 ID 26430；两窗均在移动过（0,24 → 0,37 等），点击坐标做过三轮标定（−24 / −40pt 偏移）。
- **已知限制**：合成滚轮事件（line 与 pixel 单位均试过）无法送达 ZCode 转录区；点击传递在窗口被移动后不稳定。转录区内部的逐元素悬停受阻于此。
- 证据图均在 `.scratch/compare/`（文件名前缀 `z-`=ZCode、`pi-`=PiCode）。

## 痛点逐条结论

### 痛点 1：项目分组悬停操作 —— ZCode 语义已完全证实

- **分组行悬停出现三图标**（`z-hover-group-zoom.png`）：`⋯`（更多）、列表图标（**查看文件**）、`⊕`（**新建任务**）。
- **`⋯` 菜单展开确认含「× 移除」**（`z-menu-group-more.png`）——即操作者所述"移除/查看文件/新建任务"三按钮。
- 「项目」节标题悬停出现 `⌄`（折叠）+ 排序/拖拽点 + `+`（`z-hover-group-askkb.png` 右上）。
- **会话行悬停出现垃圾桶图标**（`z-hover-session.png`，行尾 `🗑` 替代时间戳）——ZCode 的会话级移除供面。
- **空组形态**：ZCode 显示分组 + 「暂无任务」灰字（`zcode-w.png` ASK-kb-file-upload 组）。
- PiCode 现状：分组行无任何悬停操作（`pi-hover-group-*.png`），会话行悬停仅 Pin 图标（`pi-hover-session.png`）。
- 归类：**全新需求**（悬停按钮部分）+ 前置决策未决（多活动会话 1B，操作者暂挂）。

### 痛点 2：思维链/工具折叠 —— live 路径无问题，缺口在回放

- PiCode live 转录默认折叠态与 ZCode 基准一致（`1-midrun.png` vs 基准 18.54.03）。
- ZCode live 实拍（`z-hover-msg.png`/`z-hover-thinking.png`）：思考行 "思考 · 持续了 N 秒" 单行折叠、工具行 "终端 cd …" 单行折叠，密度极高。
- **resume 回放丢结构（thinking/tool 全弃）已归 ticket 14(b)**；本次不再重复取证。

### 痛点 3：排版密度 —— 实机复核坐实

- PiCode 实机落定态转录（`picode-w.png`）：单行 bullet 间隔 ~54px、表格单元格 padding 大、段落间隙大。
- ZCode live 实拍（`z-hover-msg.png`）：思考行/工具行/编辑行（含 +6 −2 diffstat）/文本段全部 ~24px 节奏；同屏信息量约为 PiCode 的 1.8–2 倍。
- 归 ticket 15，证据已补实机对照。

### 痛点 4（本次新增）：代码块/表格无块级复制 —— 双向证实

- **PiCode 无**：`Markdown.tsx` 为裸 ReactMarkdown（无 `components` 覆写、无块级供面）；实机悬停表格无任何反馈（`pi-hover-table.png`）；整条消息仅一个 Copy（消息操作行）。
- **ZCode 有**：基准截图 18.54.27 放大（`z-ref-codecell-zoom.png`）——代码格为卡片形态：**头部行 = 语言图标 + "bash" 标签（左）+ 终端图标 + 复制图标 ⧉（右，常驻非悬停）**，下方代码区，圆角边框容器。
- 表格的 ZCode 侧行为：尚未取得实机渲染样本（含 9 个表格的 transform 会话切换受阻于点击传递，见"受限项"）；实施时需补验。
- 归属：**新工单 16**。

## 第二轮验证补充（同日稍晚，严格前台协议下完成）

> 前一轮大半交互失败的根本原因：**ZCode 非前台时合成悬停/点击静默无效**。修正协议（激活 → 验证前台 → 交互）后全部打通。

### 痛点 2 的真正对标形态：整回合折叠（重大）

- ZCode 落定后转录中的「**已工作 1 分 5 秒 ›**」是一行**整回合折叠容器**：点开露出内部 `🧠 思考 · 持续了几秒`、`✨ 技能 to-spec …`、后续思考行等全部中间步骤（`z-turn-collapse-expanded.png`）。
- **收起时转录只剩：用户气泡 + 最终正文 + 文件更改条 + 消息操作行**——这正是操作者「最终显示时思维链/工具未折叠」的对标物。PiCode 目前是逐行折叠（ThinkingRow/ToolCard 各自折叠但全部平铺可见），没有回合级聚合。
- 归属：需要重塑 14(b) 的呈现目标——回放/落定态采用 ZCode 式回合折叠（「已工作 Ns」行），而非逐行平铺。

### 「打开会话」实测（ticket 14 的现场判定）

- **非活跃会话点击 → 完整 resume ✓**（合并 session：标题/Composer/转录齐全，`/tmp/pd1.png`）——机制本身没坏。
- **活会话点击 → 只读 Follow ✓**（本会话实拍 `pi-follow-raw-markdown.png`）：无 Composer、仅 Stop following；**FollowView 把 markdown 原文当纯文本渲染**（`##`、`**` 星号裸露可见）；思考/工具照旧被丢；会话结束后视图仍锁只读、无转正入口。14 号票三缺口全部实锤。
- 操作者「只有 TUI 活会话才能打开」的体感根因判定：resume 机制正常；体感来自 (a) 回放丢结构 → agent 密集会话内容残缺，(b) Follow 只读无出口。修复方向 14 不变，另加回合折叠。

### ZCode 块级供面全景（ticket 16 证据升级）

- **表格**：容器卡上方右侧四枚操作——**⧉ 复制 / ⬇ 下载 / ⤢ 展开 / →| 收起**（`z-table-hover.png`、`/tmp/tc2-zoom.png`），且**非悬停也常驻显示**。
- **代码格**（带语言标签的）：头部行 = 语言图标+标签（左）、终端钮+复制钮（右），常驻（基准截图 18.54.27 放大 `z-ref-codecell-zoom.png`）；无语言标签的裸缩进块未见头部供面。
- **消息操作行**：落定 assistant 消息**常驻**显示 `⧉ 👍 👎 🔀 (+⚓) + 时间戳`（两条实拍：有⚓与无⚓两态，锚点仅部分消息有）；悬停纯文本消息不追加新供面。

### ZCode 会话头部与新建任务（痛点 1 的新答案面）

- **标题栏 `⋯` = git 分支切换器**：搜索分支 + 分支列表 + 当前 ✓（`z-titlebar-menu.png`）。会话头部可直接切分支——PiCode 完全没有该维度。注意与 PiCode 的 History（会话树分支历史）是**不同概念**；ZCode 标题栏未见会话树入口。
- **新建任务从不弹文件夹选择器**：空态 Composer 上方自带 `📁 项目 ⌄` + ` 分支 ⌄` 两枚下拉芯片（继承当前上下文，可切换），下接四枚快捷芯片（周报总结/报错修复/PPT 制作/闲时任务）（`/tmp/newtask.png`）。对比 PiCode ⌘N → 系统选目录弹窗。这为痛点 1 提供了不依赖多活动会话（1B）的另一条路：**新建时上下文芯片化**。

### 其他新增记录

- ZCode 滚动离开底部后出现「回到底部 ↓」悬浮钮；PiCode 无（始终自动吸底）。
- ZCode 用户侧快捷动作泡「✨ To Spec」（右对齐紫调 chip）。
- ZCode 工具行内联形态：编辑行 = 铅笔图标 + 彩色文件图标 + 文件名 + 路径 + `+6 −2` diffstat（单行）；终端行 = 单行命令截断；查阅行 = 「2 文件」。PiCode 工具卡为整行卡片 + 状态徽标，形态不同但信息等价。
- ZCode 右上 toast：「✓ 向用户汇总交付」浅底深字圆角，PiCode toast 深底（ticket 11），形态差异记录。

### 第三轮补充（同日收尾）

- **回合折叠默认态**：操作者并行推进的 ZCode 会话新回合落定后，「已工作 24 秒 ›」默认收起（`/tmp/cur.png`）——回合折叠不是常开态，是默认收起、点开才展开。
- **Composer「+」菜单**四项：📎 添加附件 / @ 添加上下文 / `/` 选择能力 / **`$` 选择技能**（`z-composer-plus-menu.png`）。PiCode 的 + 仅图片选择；技能入口 PiCode 用 `/` 菜单承载。
- **ZCode 搜索 = 完整命令面板**：搜索操作/任务/文件，四类筛选（全部/操作/任务/文件），建议区（新任务 ⌘N、打开工作区 ⌘O、设置）、面板区（切换侧边栏 ⌘B/终端 ⌘J/预览、添加终端/浏览器/审查标签）、配置区（`/tmp/srch1.png`）。对比 PiCode ⌘K 仅任务搜索（票 11）。
- **回合内思考行点击展开**：尝试中因布局漂移未完成定点取证；PiCode ThinkingRow 点击展开已与基准一致，风险低，不再追。
